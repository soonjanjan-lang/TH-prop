# Surface brief: CV landing page (index.html)

Scope: whole page. Visitor mode: Persuade. Audience: academic peers (researchers, collaborators, editors). Action: contact / save the CV as a PDF. Proof: real course coordination (BEER3043); everything else is an honest [Edit] placeholder.

## Direction contract

THESIS: The CV is typeset as an economist's results table. It refuses the category default of a hero headline, a round avatar, stat counters and equal cards.

OWN-WORLD: Cool offset-paper ground, blue-black ink, booktabs rules (1.2px top/bottom, 0.6px mid), Computer Modern serif throughout with tabular figures, numbered columns (1) (2) (3), "Notes:" blocks under each table. One deep series green for structure, and the proofreader's non-repro blue reserved for links and [Edit] marks.

STORY: A peer recognises the economist's grammar within a second, reads name, affiliation and focus as Table 1, sees the record as tables, and emails or saves the PDF.

FIRST VIEWPORT: Left 7 columns: running head "Working Paper · UUM SEFB", caption "Table 1. Curriculum vitae", the name at display scale, and an affiliation table (Institution / School / Course / Location) between booktabs rules. The primary actions "Email" and "Save as PDF" sit under the table as the table's notes. Right 5 columns: "Figure 1" Lottie scatter plot whose fitted line draws itself, captioned "Illustrative data".

FORM: Regression results table, #3 of the ordered list; seed key 81ec9839. Raises: Hoffmann lattice → a strict 12-column grid that every rule snaps to. Seven-segment → absence is designed: placeholders are proof marks, not hidden. Sewing pattern → the active filter column is a solid rule, the others dashed.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
